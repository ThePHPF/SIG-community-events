# Community Events Coalition Special Interest Group

## Overview
The Community Events Coalition is one of the Special Interest Groups facilitated by The PHP Foundation. 

### Mission
This group aims to be a space where community event organizers and user group leaders can collaborate and solve common challenges together.

### How to Join

This group is still evolving, so there has never been a better time to join. Please help us guide the future of this group!

**[Subscribe to the Community Events Coalition Meeting Calendar here.](https://calendar.google.com/calendar/ical/c_a36cd4758bf99358759091716efcf8c5f54f58ba105757b7712368a93a177bfa%40group.calendar.google.com/public/basic.ics)**

**There are a few things you can do to start participating immediately:**

* [Join phpc Discord](https://discord.phpc.social/) if you aren't already there. (Special thanks to the folks hosting and moderating the phpc Discord who are kindly providing infrastructure for us to have a place to chat directly with each other!)


### Code of Conduct
By participating in this Special Interest Group, you are agreeing to adhere to [The PHP Foundation Code of Conduct](https://thephp.foundation/code-of-conduct/), so make sure you have read and understand our expectations for behavior in this space. :heart:
